# Comandos aprendidos en la Práctica 4

| Comando | Descripción |
|----------|----------|
| `pwd` | Muestra la carpeta actual. |
| `ls` | Lista los archivos y carpetas. |
| `cd` | Cambia de directorio. |
| `mkdir` | Crea una carpeta. |
| `touch` | Crea un archivo vacío. |
| `cat` | Muestra el contenido de un archivo. |
| `git init` | Convierte una carpeta en repositorio Git. |
| `git status` | Muestra el estado del repositorio. |
| `git add` | Agrega cambios al área de preparación. |
| `git commit -m` | Guarda un commit con mensaje. |
| `git log --oneline` | Muestra el historial resumido de commits. |
| `git restore` | Recupera un archivo al último commit. |
| `git branch -M main` | Cambia el nombre de la rama principal a main. |
| `git push` | Envía cambios a GitHub. |
| `git pull` | Descarga cambios desde GitHub. |
